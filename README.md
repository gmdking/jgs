# JGS
**Jolt Physics Godot Sandbox**

It's in the name, the Jolt Physics Godot Sandbox, is a sandbox, made in Godot, with Jolt Physics.
# Features:
  1. **Tons of fun presets to play with**
  2. Custom object creator
  3. **Natural feeling pick up and drop controls**
  4. **Easy duplication and deletion of objects**
  5. Simple third party maps and objects
  6. Official Map and Object store accessible in game!

Features in bold have been implemented at least partially, features that are not are in the todo list, and I'll get to work on it soon.
I've released this code to the public because
  1: I think what this project contains could be particularly useful for other people
  2: I wan't people to be working on this with me collaboratively, as I do NOT have the skills required to implement the above in the time allotted.
